WCAG 2.2 Violation Detection with Strands Decider

Completed View on Kaggle

Overview

This project trains a Strands Decider model to classify HTML chunks as having WCAG 2.2 accessibility violations. The model is trained on a combination of real-world web crawl data (via Playwright + axe-core) and synthetic datasets.

The final model can be used to predict whether a given HTML snippet violates any of the WCAG 2.2 success criteria.

How to Use

The model is available as a strands-decider command-line tool. After training, you can serve it and make predictions: 

# Serve the model
strands-decider serve checkpoints/hobson-2b-wcag --port 8000

# Make a prediction
curl -X POST http://localhost:8000/v1/systemone \
  -H "Content-Type: application/json" \
  -d '{
    "state": "<button style="width: 20px; height: 20px; padding: 0;">Login</button>",
    "questions": {
      "wcag_2_5_8_target_size": {
        "type": "noun",
        "instructions": "Does this button meet the WCAG 2.2 minimum target size of 24x24 CSS pixels?"
      }
    }
  }'

About the Model

The model architecture is based on the Strands Decider framework, which adapts the JevBench multi-step reasoning setup for accessibility violation detection.

Training data includes:

  • Real-world HTML chunks from CDC.gov (via Playwright + axe-core)
  • Synthetic WCAG-generated examples
  • Multi-step reasoning datasets (ContractNLI, MuSiQue, etc.) for reasoning capability

Model trained and evaluated on Kaggle.
